## 2. AI 분석 프로세스 3단계 구분

- **전체를 한 영역으로 묶음**: `.ai-process-wrap`으로 3단계를 감싸고, 배경(흰색 계열)·테두리·둥근 모서리·패딩을 줘서 한 블록처럼 보이게 했습니다.
- **단계별 카드 구분**:
  - 각 단계(사진 업로드 / 피부톤·채도 분석 / 퍼스널컬러 제공)를 **카드 형태**로 두고, 배경·테두리·그림자로 구분했습니다.
  - 1단계는 **왼쪽 보더(primary)**, 2단계는 **secondary**, 3단계는 **primary-dark** 색으로 왼쪽 강조선을 넣어 단계별로 구분되게 했습니다.
- **간격**: 단계 카드 사이 gap을 16px로 두어 서로 떨어져 보이도록 했습니다.

## 1. FAQ 모션 부드럽게

- **열림/닫힘**: 답변 영역에 `max-height` + `transition: max-height 0.4s cubic-bezier(0.4, 0, 0.2, 1)` 적용해 부드럽게 펼쳐지고 접히도록 했습니다.

- **트리거**: `background`, `border-left-color` 에 0.3s ease 트랜지션을 넣었습니다.

| 카테고리 | 봄웜 | 여름쿨 | 가을웜 | 겨울쿨 |
|---------|------|--------|--------|--------|

| 패션 | 봄웜 패션 | … | … | … |

**나중에 염색약·패션을 다시 보이게 하려면**

`ai-analysis.js`에서 `PRODUCT_CATEGORIES_VISIBLE` 배열에 `'hairDye'`, `'fashion'`만 추가하면 됩니다.

```js
// 지금 (염색약·패션 숨김)
const PRODUCT_CATEGORIES_VISIBLE = ['lip', 'blush', 'eyeShadow'];

// 염색약·패션까지 모두 보이게 할 때
const PRODUCT_CATEGORIES_VISIBLE = ['lip', 'blush', 'hairDye', 'eyeShadow', 'fashion'];
```

위 한 줄만 바꾸면 염색약·패션 카테고리가 다시 나타납니다.
